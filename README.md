# PowerShell Automation for Azure AVD & Nerdio

This repository contains PowerShell scripts focused on automating
Azure Virtual Desktop (AVD) and Nerdio workflows.

## Folder Structure
- 01-Basics – PowerShell fundamentals
- 02-Windows-Automation – Services, logs, installs
- 03-Azure-PowerShell – Azure resource automation
- 04-Azure-AVD – Host pool and session management
- 05-Golden-Image – Image lifecycle automation
- 06-Nerdio – Pre/Post login scripts
- Utils – Logging and error handling

## Skills Demonstrated
- Azure AVD administration
- Nerdio automation
- PowerShell scripting
- Infrastructure automation
